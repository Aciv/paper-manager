# paper_manager 1.0.1

本次更新重点改善批量导入源信息和处理进度查看。

## 新增与改进

- 文件和 URL 导入可同时携带标题、作者、摘要、DOI、标签等源信息；批量导入支持逐篇配置。
- 可明确选择“跳过自动源信息查询”。文档解析和参考文献提取继续执行，需要时仍可手动查询。
- 重复导入默认只补缺失字段，保留已有处理设置；也可选择保持源信息，或覆盖本次提供的字段。
- 前端区分文件入库、已解析可阅读、后台处理中、失败及主动跳过，并展示原因与重试入口。
- MCP 批量状态新增阅读就绪和工作流汇总，报告部分成功与缺失文档；Agent 可在单篇解析完成后
  开始写 notes，无需等待整批导入或所有外部查询结束。

## 修复

- 源信息在解析任务发布前写入，避免导入字段与后台自动处理发生先后顺序竞争。
- 源信息写入失败时保留已导入文件和文档 ID，明确报告部分成功。
- 重复导入的补缺操作在数据库事务内完成，避免并发覆盖已有字段或用户明确清空的内容。
- 本地文件导入遇到任务入队失败时，MCP 仍返回已保存的文档 ID，方便直接重试解析。
- 重新解析或提取不会绕过已保存的“跳过自动源信息查询”选项。

## 下载与更新

- Windows：下载 windows-x86_64 的 ZIP；Linux：下载 linux-x86_64 的 tar.gz；
  Apple 芯片 Mac：下载 macos-arm64 的 tar.gz。请完整解压后运行。
- 更新前通过管理页退出 Launcher。把完整的旧 `data/` 目录复制到新版解压目录，
  需要保留自定义端口和启动设置时，一并复制 `launcher.json` 与 `.launcher_env`。
- 请保留 `data/runtime.json` 中的原配置；启动时会自动升级数据库，已有论文和 notes 可继续使用。
- 旧文档默认继续自动查询源信息，无需重新导入。请使用普通用户运行，并优先选择纯英文路径。
