# 历史打包与维护材料

这里保留旧的安装器、D0–D4 设计、验收记录和工作流快照，供追溯使用。
它们不代表当前用户包的结构、当前提交已通过的平台或当前工作流入口。

- `desktop/`：旧构建说明、Launcher 框架说明、受管理安装规则和历史证据。
- `installer/`：旧受管理安装器；仅显式内部回归包可能引用，不进入用户包。
- `workflows/`：替换前的工作流快照，不在 `.github/workflows/` 中运行。

当前入口见 [发行构建](../desktop/BUILD.md)、[用户操作](../desktop/USER.md)及
[当前验收说明](../desktop/VALIDATION.md)。旧记录中的原始路径与链接可能属于对应历史提交。
